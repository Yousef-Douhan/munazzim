# مُنظِّم — منظّم وقتك مع تذكيرات تلقائية على واتساب والإيميل

موقع لتنظيم جدولك اليومي والأسبوعي والشهري والسنوي (دراسة، عمل، أسرة، شخصي)، **يرسل لك التذكيرات وحده** حتى وأنت مغلق الموقع:

| ماذا يصلك | متى |
|---|---|
| 🔔 تذكير بكل مهمة | قبل موعدها بالوقت الذي تختاره (عند الموعد، 5 د، 10 د، … ساعتين) |
| ☀️ جدول اليوم كاملاً | كل صباح في الوقت الذي تحدده |
| 🗓️ خطة الأسبوع | كل سبت صباحاً |
| 📆 خطة الشهر + تقدم أهدافك السنوية | أول يوم من كل شهر |
| 🌙 مراجعة المساء (ما لم يُنجز) | اختياري، في الوقت الذي تحدده |

كل رسالة تصل على **واتساب** و**الإيميل** معاً (تقدر تطفئ أي قناة من الإعدادات).

التقنية: Node.js 18+ **بدون أي مكتبات خارجية** (لا `npm install`).

---

## الخدمات المجانية المستخدمة

| الخدمة | الدور |
|---|---|
| **CallMeBot** | إرسال واتساب إلى رقمك (مجاني للاستخدام الشخصي) |
| **Brevo** | إرسال الإيميل (300 رسالة يومياً مجاناً) |
| **Upstash Redis** | حفظ بياناتك بشكل دائم |
| **Render** | استضافة الموقع |
| **cron-job.org** | يوقظ الخادم كل 5 دقائق حتى لا ينام ويفوّت التذكيرات |

---

## خطوات الإعداد (حوالي 20 دقيقة)

### 1) واتساب — CallMeBot
1. افتح صفحة واتساب على موقع CallMeBot: https://www.callmebot.com/blog/free-api-whatsapp-messages/ وانسخ **رقم البوت الحالي** منها (الرقم يتغير أحياناً، فخذه من الصفحة نفسها).
2. احفظ الرقم في جهات الاتصال، ثم أرسل له على واتساب هذه الرسالة بالضبط:
   ```
   I allow callmebot to send me messages
   ```
3. خلال دقيقتين يرد عليك برسالة فيها **APIKEY**. احفظه.
   (إذا لم يصلك الرد، أعد المحاولة بعد 24 ساعة.)

### 1-ب) بديل: واتساب عبر Green-API (إذا كان بوت CallMeBot ممتلئاً)
1. سجّل على https://green-api.com، وأنشئ **instance** على خطة **Developer** المجانية (حدّها 3 محادثات، وهذا يكفي لإرسال التذكيرات لرقمك).
2. اربط بها **رقم واتساب ثانياً** (جوال قديم أو رقم أحد أفراد العائلة): امسح رمز QR من «الأجهزة المرتبطة» في واتساب. هذا الرقم هو الذي سيرسل لك.
3. انسخ من صفحة الـ instance القيم `idInstance` و `apiTokenInstance` و `apiUrl`، وضعها في `.env`:
   ```
   WHATSAPP_PHONE=+9725XXXXXXXX      # رقمك الأساسي الذي تصله التذكيرات
   GREENAPI_ID_INSTANCE=...
   GREENAPI_API_TOKEN=...
   GREENAPI_API_URL=...
   ```
عند تعبئة قيم Green-API يستخدمه الموقع تلقائياً بدل CallMeBot.

### 2) الإيميل — Brevo
1. سجّل حساباً مجانياً على https://www.brevo.com
2. من **Senders, Domains & Dedicated IPs ← Senders** أضف إيميلك ووثّقه بالرابط الذي يصلك.
3. من **SMTP & API ← API Keys** أنشئ مفتاحاً جديداً وانسخه.

### 3) التخزين — Upstash
1. سجّل على https://upstash.com وأنشئ **Redis Database** (الخطة المجانية).
2. من صفحة القاعدة انسخ **UPSTASH_REDIS_REST_URL** و **UPSTASH_REDIS_REST_TOKEN**.

### 4) ارفع المشروع على GitHub
```bash
cd munazzim
git init && git add . && git commit -m "munazzim"
git branch -M main
git remote add origin https://github.com/Yousef-Douhan/munazzim.git
git push -u origin main
```
> ملف `.env` مستثنى في `.gitignore`، فلن تُرفع أسرارك.

### 5) الاستضافة — Render
1. سجّل على https://render.com واختر **New ← Blueprint**، واربطه بالمستودع (Render يقرأ ملف `render.yaml` تلقائياً).
2. سيطلب منك قيم المتغيرات، فأدخل:

| المتغير | القيمة |
|---|---|
| `APP_PASSWORD` | كلمة مرور الدخول للموقع |
| `WHATSAPP_PHONE` | رقمك بالصيغة الدولية، مثل `+9725XXXXXXXX` |
| `CALLMEBOT_APIKEY` | المفتاح من الخطوة 1 |
| `BREVO_API_KEY` | المفتاح من الخطوة 2 |
| `EMAIL_TO` | الإيميل الذي تصل إليه التذكيرات |
| `EMAIL_FROM` | الإيميل الموثّق في Brevo (يمكن أن يكون نفسه) |
| `UPSTASH_REDIS_REST_URL` / `UPSTASH_REDIS_REST_TOKEN` | من الخطوة 3 |

`SESSION_SECRET` و `CRON_SECRET` يولّدهما Render تلقائياً، و`TIMEZONE` مضبوط على `Asia/Hebron`.

3. بعد النشر تحصل على رابط مثل `https://munazzim-xxxx.onrender.com`. افتحه وادخل بكلمة المرور.

### 6) إبقاء الخادم صاحياً — cron-job.org
خوادم Render المجانية تنام بعد 15 دقيقة بدون زيارات، وهي نائمة لا ترسل شيئاً. لذلك:
1. انسخ قيمة `CRON_SECRET` من صفحة **Environment** في Render.
2. سجّل على https://cron-job.org وأنشئ Cronjob:
   - **URL:** `https://munazzim-xxxx.onrender.com/api/tick?key=CRON_SECRET`
   - **Schedule:** كل 5 دقائق
3. هذا الرابط يوقظ الخادم، ويفحص التذكيرات في كل مرة.

### 7) جرّب
في الموقع افتح **الإعدادات**، وتأكد أن واتساب والإيميل يظهران بالأخضر في «حالة الخادم»، ثم اضغط **اختبار واتساب** و**اختبار الإيميل**.

## التشغيل على جهازك (للتطوير)
```bash
cp .env.example .env     # واملأ القيم
npm start                # http://localhost:3000
```
بدون Upstash تُحفظ البيانات في `data.json`، والتذكيرات تعمل ما دام الجهاز والخادم يعملان.

## كيف يعمل
- `server.js`: خادم HTTP، وتسجيل دخول بكوكي موقّعة، و API للبيانات.
- `lib/scheduler.js`: كل 30 ثانية (وعند كل طلب `/api/tick`) يحسب الوقت بتوقيت `TIMEZONE`، ويرسل ما حان وقته. أي رسالة تأخرت حتى 20 دقيقة (مثلاً لأن الخادم كان نائماً) تُرسل عند الاستيقاظ.
- كل رسالة تُسجَّل لكل قناة على حدة، فلا تتكرر حتى لو أُعيد تشغيل الخادم. إذا فشل الإرسال يحاول 3 مرات كحد أقصى.
- `lib/notify.js`: CallMeBot (رسالة كل 3 ثوانٍ على الأقل) و Brevo.
- `lib/store.js`: Upstash Redis عبر REST، أو ملف محلي.

| Endpoint | الوصف |
|---|---|
| `POST /api/login` | تسجيل الدخول |
| `GET/PUT /api/state` | قراءة/حفظ المهام والأهداف والإعدادات |
| `GET /api/status` | حالة القنوات والتخزين وآخر فحص |
| `POST /api/send` | إرسال فوري: `{"kind":"daily"\|"weekly"\|"test","channel":"whatsapp"\|"email"}` |
| `GET /api/tick?key=…` | فحص التذكيرات (لـ cron-job.org) |
| `GET /health` | فحص صحة الخادم |
